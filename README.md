# 藍予測 1.1.0

楽天証券「らくオプ」の判定時刻に合わせて、為替の予測価格・推定範囲・経済イベントを確認する個人用Androidアプリです。楽天証券の公式アプリではありません。

## インストールと最初の操作

1. `aiforecast-1.1.0-personal.apk` をAndroidにインストールします。Android 8.0以降と、更新されたAndroid System WebViewを使用してください。
2. 「設定」→「Continue with ChatGPT」で外部ブラウザーを開き、ログインしてChatGPTプランの利用を許可します。
3. アプリに戻り、利用できるモデルを選択します。モデル一覧は接続したアカウントから取得します。
4. 「予測」で通貨ペアと回号を選び、レートを更新します。
5. 「イベント」→「GPTで時事を調査」で経済・中央銀行・政治イベントを検索します。BLSの米国指標予定はログインなしで取得できます。
6. 「GPTで分析」を押すと、その時点のレート・確定足・指標・既知イベントから予測を作成します。
7. 「目標レートとの比較」に、楽天の取引画面にある目標レートと上・下の購入価格を入力します。「一覧」で複数の目標レートを比較できます。

AIはChatGPTプランの利用枠を消費します。独自のOpenAI APIキーは不要です。利用できるモデルやWeb検索はアカウント・ワークスペースの許可に依存します。Web検索が拒否された場合、推測したニュースを検索済みとして登録しません。

土日や配信停止中、古いレート、確定足の不足時は、未来の予測と期待損益を表示しません。設定の「デモを表示」で架空データの画面を確認できます。デモの予測履歴は実データの成績に混ぜません。「実データに戻る」で解除できます。

## 機能

- USD/JPY、EUR/JPY、GBP/JPY、AUD/JPY、EUR/USD。
- らくオプの10回号、購入締切のカウントダウン、日付選択、米国夏時間の自動判定と手動指定。
- 5・15・30・60・120分先、および選択した回号の判定時刻の予測中央値と10%・90%分位。予測対象は24時間以内です。
- 参考レートと予測範囲のチャート、イベント時刻・判定時刻・入力した目標レートの表示。
- EMA、RSI、MACD、ATR、ボリンジャーバンド、支持・抵抗帯。1分・5分・15分足の傾向比較。
- BLS公式カレンダーの取得、GPTのWeb検索による予定・ニュースの補完、手動追加、出典リンク。
- 市場予想を上回る・下回る場合の条件別シナリオ。未確認の市場予想や発表値を埋めません。
- 重要イベントの約10分前の端末通知。OSの省電力制御により遅れる場合があります。端末再起動後はアプリを開いて再登録してください。
- 目標レート別の上下確率、購入価格に応じた損益分岐確率・理論期待損益。
- GPT予測の自動保存、統計予測の手動保存、過去の予測と参考1分足の照合。
- 先読みをしない統計モデルの過去検証と、「価格が変わらない予測」との誤差比較。
- 楽天の実際の判定価格を手動で記録し、保存時の購入価格で1枚当たりの結果を計算。
- 分析に送信した内容の確認、履歴JSONの書き出し・復元、過去検証用の1分足CSV読込。
- フォアグラウンドサービスによるAI処理。別画面・別アプリへの移動後も続行し、完成した応答を保存。OS強制終了や通信断後は完成済みの結果を保持し、再分析できます。

## 期間指定のバックテスト（1.1.0）

「検証・履歴」から通貨・開始日・終了日・予測時間（5/15/30/60/120分）を指定します。「過去データを取得」後、「統計モデルを検証」または「GPTで検証」を選択してください。GPTの件数は利用枠を考慮して指定でき、期間全体から均等にケースを選びます。完成したケースを保存し、未完了・失敗分だけ再開できます。結果とプロンプトはJSON出力できます。

通常の各回号の判定時刻から指定時間だけ前に予測します。予測時点の外部MIDを仮の目標レートとし、判定時刻の参考MIDが以上なら上、未満なら下として採点します。同値は上です。判断・判定時刻に終了する1分足の終値を使用します。足不足・欠損ケースは除外し、件数を表示します。楽天の過去の実際の目標レート・購入価格・正式判定を再現したものではありません。

GPTの検証は日付・通貨名・価格水準を匿名化し、現在価格を100に正規化します。未来の足・正解は送信しません。1件ごとに独立したResponses API呼び出しで、Web検索や他ケースの履歴は渡しません。匿名化は記憶の影響を完全に除く保証ではありません。ニュースの当時点アーカイブがないためニュースは含みません。本番のニュース込み成績は将来の予測記録から別に検証する必要があります。

正解率に加え、常に上・常に下・直前30分の方向、価格変化なしの誤差と比較します。GPTは同じケースの統計モデルと比較。失敗・未完了は正解率の分母から除き別表示します。日単位ブートストラップ区間は、画面では10営業日・30件以上かつ全問正解／不正解でない場合に表示します。少数標本での区間を過信しないでください。固定購入価格による損益例は仮定であり実利益ではありません。

事前に固定した旧版の統計エンジンで2026年10月5日〜11月13日（30営業日）の5通貨×10回号を実測しました。各時間幅1,500件、正解率は5分47.5%、15分50.5%、30分47.2%、60分48.3%、120分48.4%。全時間幅で常に上を下回り、中央値の価格誤差も価格変化なしより大きい結果でした。モデルへの優位性は確認できません。測定後のパラメータ調整は行っていません。同梱ベンチマークはこの統計結果で、GPTの成績ではありません。

## 価格と確率について

レートはGMOコインの認証不要の公開FX APIから取得します。BID・ASKのローソク足を平均したMID近似を使用します。高値・安値は厳密なMID足ではありません。楽天の正式な判定価格とは一致しません。楽天の目標レート・オプション購入価格・正式判定結果を自動取得する機能はありません。

統計モデルは、EMAの傾きから求めた減衰ドリフトと、直近リターン・ATRによる変動幅を用います。既知の重要イベントを含む予測では範囲を拡大します。GPTはこれらの材料と提示された足・イベントから分位点を推定します。

どちらの予測範囲も実測の包含率で校正されていません。「10%・90%分位」はモデルの出力であり、実際に80%が収まると検証された範囲ではありません。上下確率は分位点から対数正規分布を近似した計算値で、実測の勝率ではありません。外部レートと楽天の価格差や、イベント時の価格ジャンプを十分に反映できません。期待損益のプラスだけでは優位性の証明になりません。

- 1枚のペイアウト：1,000円
- 損益分岐確率：購入価格 ÷ 1,000
- 理論期待損益：1,000 × 成立確率 − 購入価格
- コール：判定価格が目標レート以上
- プット：判定価格が目標レート未満
- 同じ目標レートで上下を両方保有して満期を迎える場合：合計損益は1,000円から両方の購入価格を引いた値

このアプリから発注は行いません。通常の回号予定は表示しますが、楽天による回号休止・臨時変更の自動確認は行いません。実際の購入可否と価格は楽天の取引画面で確認してください。

## データ・認証

公式のSign in with ChatGPTを使用。動的クライアント登録、Authorization Code + PKCE、state・nonce、JWKSによるIDトークンの署名・issuer・audience・expiry検証、トークン更新、ログアウト時の失効を実装しています。

アクセストークン・更新トークン・IDトークンはAndroid KeystoreのAES-GCMで暗号化し、バックアップ対象外領域に保存します。画面のJavaScript、書き出した履歴、ログへは渡しません。ChatGPTパスワードや楽天証券の認証情報を入力する画面はありません。

推論は公開Responses APIのみを使用し、`input`配列、`store:false`、`stream:true`で送信します。`response.completed`を受信した場合だけ完成として扱います。利用上限エラー、途切れたストリーム、不完全なJSONを予測として反映しません。ChatGPTの非公開backend-apiは使用しません。

送信対象は選択した通貨ペア・公開レート・確定足・計算指標・既知イベント・手動入力した目標レートと購入価格です。ChatGPTの過去の会話やメモリーは読み取りません。AI出力は宣言的なJSONだけを扱い、コードを実行しません。

個人用のローカル実行版としてソースを同梱しています。商用提供・有料化・リモートホスティングへ変更する際は、OpenAIやデータ提供元のその時点の提供条件を確認してください。

## ビルド

Android Studioでルートを開いてビルドできます。Android Gradle Plugin 8.7.3、SDK Platform 35、Java 17以降を使用します。JavaのみでABI固有のネイティブライブラリはありません。

Gradleを使わない代替ビルドも同梱しています。Java 17以降、ECJ 3.39.0、Android Platform 35とBuild Tools 35.0.0を指定します。

```sh
python3 scripts/build-apk.py \
  --platform /path/to/android-sdk/platforms/android-35 \
  --tools /path/to/android-sdk/build-tools/35.0.0 \
  --ecj /path/to/ecj.jar \
  --keystore /private/path/aiforecast-personal.p12 \
  --password-file /private/path/password.txt \
  --out /path/to/aiforecast.apk
```

同じアプリに上書き更新するには同じ署名鍵が必要です。別添の更新用署名鍵バックアップは私的に保管し、ソース公開に含めないでください。

```sh
node tests/engine.cjs
node tests/backtest.cjs
npm install
AF_CHROMIUM=/path/to/chromium npm run test:ui
AF_CHROMIUM=/path/to/chromium node tests/backtest-ui.cjs
```

UIテストはChromium/Chrome Headless ShellとPlaywright Core 1.57.0を使用します。JVMテストはJSON-java 20250517とJava 17以降が必要です。`ProtocolTest.java`は`Net.java`・`EventFeed.java`と一緒にコンパイルします。BLS ICSファイルを引数に与えると実日程の解析も検証します。`MarketSmoke.java`は実際の公開APIへ読み取りアクセスします。企業プロキシ環境ではJVMのHTTPSプロキシ設定が必要です。
